# Telegram 模拟

## 一、整体架构

### 客户端 Client

[x] 网络通信模块
[ ] UI（暂无
[ ] 本地缓存（SQLite/文件）（暂无

| 模块 | 作用     |
| ---- | -------- |
| send | 发送信息 |
| recv | 接收信息 |

### 服务端 Server

[x] 连接管理（长连接）
[ ] 消息路由
[ ] 用户管理
[ ] 存储（数据库）

| 模块      | 作用           |
| --------- | -------------- |
| accept    | 接受新连接     |
| clients   | 记录所有客户端 |
| recv      | 接收信息       |
| broadcast | 转发信息 ｜    |

### 通信协议

- TCP(基于 socket)
- 纯文本
